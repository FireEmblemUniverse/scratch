# Reverse Engineering

Cool, we know how to look at vanilla code. But that's not all that useful when
90% of projects these days are using Skill System(s), and otherwise are so
flattened by patches written in 2017 that the decomp won't be helpful, right...?

As it turns out, the decomp is *great* for understanding other people's custom
code, even if that code is written in assembly!

If you are interested in learning about the skill system more directly, I'd
recommend reading [this](https://feuniverse.us/t/the-skill-system-and-you-maximizing-your-usage-of-fe8s-most-prolific-bundle-of-wizardry/8232) instead.
